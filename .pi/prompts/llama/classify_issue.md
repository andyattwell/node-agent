# Classify Issue

Classify the issue and respond with exactly one token: `feature`, `bug`, `chore`, or `0`.

## Rules

- Output **only** that token. No explanation, no preamble.
- `feature` - new functionality, UI changes, enhancements
- `bug` - defect or incorrect behavior to fix
- `chore` - build, tooling, deps, docs-only, refactors without new behavior
- `0` - does not match feature/bug/chore
